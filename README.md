# Malaysian Guru 4D Hotline

A mobile-first, responsible membership website for Malaysian 4D informational tips and premium analysis. It carries the owner-provided Malaysian Guru 4D Hotline official logo throughout global website surfaces. The frontend is built with React, TypeScript, Tailwind CSS, Wouter, and Supabase.

The repository includes a complete public site, authentication screens, free and premium content routes, account dashboard, payment-evidence workflow, administrator workspace, RLS migration, SEO files, and deployment checklist. The application is intentionally designed not to create or display fabricated predictions, results, testimonials, payment approvals, or claims of guaranteed outcomes.

For database configuration, RLS policies, owner-admin promotion, domains, redirect URLs, and launch testing, read [`DEPLOYMENT.md`](./DEPLOYMENT.md).
